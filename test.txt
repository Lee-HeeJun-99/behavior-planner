8. **마지막으로 CAN 제어 송신 전환**

이 단계부터 차량에 제어 명령이 전달됩니다. 경로·장애물 표시를 확인한 뒤 실행하세요.

```
source /home/wgr/behavior_ws/validation/heading/env.sh

# 기존 CAN 브리지만 종료
pkill -INT -f '^/usr/bin/python3 .*erp42pro_interface/can_bridge_node'

# 송신 모드로 실행
ros2 run erp42pro_interface can_bridge_node --ros-args \
  -p can_channel:=can0 \
  -p receive_only:=false \
  -p max_speed_kph:=10.0

```
